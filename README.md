## Projects

### [Designing for Trust](https://github.com/t00th-blip/designing-for-trust)
Why churches function as trusted civic spaces for immigrant elders while public libraries and
recreation centers go unused. Sole evaluator on an IRB-approved mixed-methods study: 26 surveys,
16 semi-structured interviews, a participatory neighborhood-mapping activity, every instrument
built in English and Spanish.
**Tools:** R · bilingual instrument design · qualitative coding · participatory mapping
**Shows:** full evaluation lifecycle — logic model, evaluation plan, IRB protocol, analysis, policy brief
**Status:** Complete. Brief presented to the ASU Watts College board and selected for publication.

### [Police Staffing in a Tourist Economy](https://github.com/t00th-blip/lake-havasu-staffing)
A workload-based patrol staffing model for a city of 62,400 residents that absorbs roughly 1.6
million annual visitors and logged 50,493 calls for service in 2025. 44 months of record-level
data obtained by public records request and extracted from PDFs into one analysis-ready dataset.
**Tools:** R · SQL · systematic literature review · peer-city benchmarking
**Shows:** administrative data engineering, benchmarking, costed options for non-technical decision-makers
**Status:** In progress (Fall 2026). Client: Lake Havasu City Police Department.

### [Power Hour Evaluation Design](https://github.com/t00th-blip/power-hour-evaluation)
A complete evaluation design for a 27-site youth academic program: theory of change, logic model,
M&E plan, quasi-experimental pre-post design with matched comparison and difference-in-differences
for summer learning loss, analysis plan, bilingual reporting plan, and budget.
**Tools:** logic modeling · M&E planning · quasi-experimental design · difference-in-differences
**Shows:** design judgment — what to measure, what the design can and cannot claim, what it costs
**Status:** Design only, never fielded. Academic exercise, not commissioned by the organization.

### [montyhall](https://github.com/t00th-blip/montyhall)
R package simulating the Monty Hall problem, with documented functions, a NAMESPACE, and
generated man pages. Course exercise in R package structure.
**Tools:** R · package development · roxygen documentation
